# Aman Sachan (AmSach) Portfolio

Neovim-inspired developer & systems researcher portfolio for **Aman Sachan (`AmSach`)**, built as a zero-dependency static site with an animated code-wall intro, 8 color themes, keyboard-first navigation (`j`/`k`, `:theme`, `t`, `Enter`), and interactive code previews.

## Local Preview

```bash
python serve.py 8767
# Open http://127.0.0.1:8767/
```
